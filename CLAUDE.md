# bok — notes for Claude

- Plan and phase status: `docs/PLAN.md`. Work phase by phase.
- npm workspaces (no pnpm). Workspace packages are consumed as TypeScript source (`exports` → `src/*.ts`, explicit `.ts` import extensions).
- SvelteKit **3**: imports use `#lib/...` (subpath imports, not `$lib`), env vars are declared in `apps/web/src/env.ts` with `defineEnvVars` and read from `$app/env/private`; adapter/config live in `vite.config.ts` (no `svelte.config.js`); `.env` is at the repo root (`env.dir: '../..'`).
- i18n: Paraglide, messages in `apps/web/messages/{en,pl}.json` — every UI string goes through `m.*()` in both languages; avoid plural-sensitive phrasing (Polish plurals).
- Never construct services at import time in the web app — use `services()` from `#lib/server/services.ts` (lazy; `vite build` imports server code).
- better-auth sessions live in Valkey as well as Postgres: revoke via `auth.api.*`, never by deleting `session` rows.
- Schema changes: edit `packages/db/src/schema`, then `npm run db:generate` and commit the SQL in `packages/db/migrations`.
- Text mentions: `@user`, `#tag`, `$book`.
- Deploy: Kustomize in `deploy/`; the user writes the IngressRoute — don't add Ingress resources.
- adapter-node 6 ignores `ORIGIN`; request origin comes from headers (default protocol https). Local prod tests over http need `PROTOCOL_HEADER=x-forwarded-proto` + that header.
- Scanning: decode logic in `apps/web/src/lib/scanner` (filter is unit-tested), offline queue in `lib/client` (Dexie, one DB per user). Copy ids are generated on the device so retries are idempotent. Keep Dexie/zxing out of the main bundle (lazy imports only).
- Service worker caches `/`, `/scan`, `/library` (+ their `__data.json`) and all `/_app/immutable/*` on first use; sign-out wipes local data via `wipeLocalData()`.
- Storage: rooms (`locations`) → furniture (`containers`, layout JSON in cm) → `sections` (cells keyed by col/row; ids stay stable across layout edits). Layout maths lives in `@bok/core` `layout.ts` (shared by the designer and the server). Every storage row carries `household_id`; check membership through `shelves.assertMember` / the `owned()` helpers.
- E2E suites in `apps/web/e2e` (`npm run test:e2e`, needs `npm run dev` and `CHROME`): scanner (fake camera), manual add, shelves.
- Reading: `reading_states` (one status per user×work) + `reads` (each reading, rereads separate) + `reading_events` (timeline). Logic in `packages/server/src/reading.ts`; pure maths (estimate, pace, diary grouping, goal) in `@bok/core` `reading.ts`. The daily `reading-stuck` worker job applies the 30-day rule.
- Drizzle gotcha: in single-table queries column refs render unqualified, so correlated subqueries must spell out `"table"."column"` explicitly.
- Polish plurals: use `daysText()`-style helpers with `Intl.PluralRules` (`one/few/many` message variants) rather than "{n} dni".
- Visibility: SQL `can_view(viewer, owner, visibility)` (migration 0003) is the single source of truth in queries; `@bok/core` `canView` is its TS twin and both are tested against the same matrix. Friends count as followers.
- Notifications: `notifications.notify()` stores, NOTIFYs (`bok_notify` → SSE `/api/v1/events`) and delivers push/email. New types go in `NOTIFICATION_TYPES` (+ texts there and `notif_*` messages).
- Paraglide: CLI (`npm run check`) and the Vite plugin must both use `locale-modules`, or a running dev server breaks when the CLI regenerates files. Don't put `@{` in messages (breaks the generated JSDoc).
- Readlists: order is a fractional key (`@bok/core` `keyBetween`) in a `COLLATE "C"` column (migration 0005) — locale collations break the order. Moving rewrites only the moved row.
- Link previews: `OgMeta.svelte` on the page + `/og/{l,book,u}/[x].png` endpoints (`lib/server/og.ts`: satori + resvg + sharp, all native deps of `@bok/web`). Image URLs carry `?v=<content hash>`; keep `og-version.ts` free of the renderer so pages don't load it.
- Posts: canonical text format parsed by `@bok/core` `parsePost` (books `$[Title](book:id)`, `@handle`, `#tag`, `||spoiler||`, **bold**, _italic_, links) and rendered by `PostBody.svelte` from the tree — never `{@html}`. Editor form via `toEditable`/`fromEditable`. Feed in `posts.feed()` (UNION of posts/reads/lists, keyset cursor). OG card fonts lack ⚠/▒ — spell things out in preview images.
- Lending: `loans` (each side a user id or a name; `copy_id` only when lending my copy; unique active loan per copy). Logic in `packages/server/src/loans.ts`, date maths (due choices, reminder days, local date) in `@bok/core` `loans.ts`. Reminders = hourly `loan-reminders` job, from 9:00 recipient-local, exactly-once via the notification `dedupe_key` — never send reminders without one. Copy `state` follows loans (`lent` ↔ `shelved`). Blocking cancels `requested` loans in `social.block`.
- Import: `@bok/core` `import.ts` parses Goodreads / Polish-header CSVs (`parseImportFile`); `packages/server/src/imports.ts` stores rows (`import_rows`), the `import-run` job matches + applies them idempotently. Imported reads keep `finished_at` null (stays out of feeds). Export in `exports.ts` (CSV + JSON). Stats maths in `@bok/core` `stats.ts`. The import e2e suite needs `npm run dev:worker`.
- OG fonts: the app's own Baloo 2 / Nunito as WOFF (satori can't read WOFF2); latin and latin-ext subsets must have different names (`Serif`/`SerifExt`, used as `'Serif, SerifExt'`) or Polish letters render as boxes. Preview colours are the Garden light tokens copied into `og.ts` `C` — keep them in sync with `layout.css`, like the icons (`static/icons`), `manifest.webmanifest`, the `theme-color` metas in `app.html` and `email.ts`. Bump `RENDERER` in `og-version.ts` when the card look changes.
- Dates: a user's "today" is their profile timezone (`localDate`), never `toISOString().slice(0, 10)`; feed times come from the DB clock (`now()`), not the app's. Malformed ids from URLs: wrap service calls in `guard()` (maps Postgres 22P02 to 404).
- Coverage: `npm run test:coverage` (unit + DB tests, v8).
- Look ("Ink & Paper", cel-shaded, Garden palette): tokens in `apps/web/src/routes/layout.css` — pastel `--accent`/`--apricot` are fills only (text on them is `--accent-ink`); readable accent text is `--accent-text` (`.text-accent` is remapped to it); outlines/shadows use `--outline` (ink in light, near-black in dark). Tailwind `dark:` follows Settings *and* the system theme (custom variant in `layout.css`). Cards/buttons: 2–2.5px outline + hard offset shadow, no blur. `font-serif` = Baloo 2 (display; Fredoka was dropped: no ą/ę/ż), body Nunito, self-hosted latin + latin-ext only — check new fonts for all Polish letters. Fixed bars above the tab bar sit at `bottom-[calc(7.5rem+env(safe-area-inset-bottom))]`.
- Server conventions: `Forbidden`/`NotFound` live in `packages/server/src/errors.ts`; media URLs come from `mediaUrls(storage)` (`media.ts`) — don't re-declare `cover`/`avatar` helpers. Routes call services; no Drizzle queries in new route files. "This year" for a reader is `reading.currentYear(userId)`.
- Keyset cursors carry the timestamp as Postgres text with microseconds (`cursorTime` in `posts.ts`) — a JS `Date` rounds to ms and skips rows.
- Push subscriptions: endpoints must pass `isPushEndpoint` (`@bok/core`, allowlist of browser push services) because the server POSTs to them.
- Shared UI classes in `layout.css`: `.popover` (menus), `.icon-btn`, `.meter` + `.meter-fill`, `.segmented` (selected via `aria-selected`/`aria-pressed`), `.card-band`. No blurred shadows (`shadow-lg` etc.) and no emoji as icons — add a Lucide path to `Icon.svelte`.
